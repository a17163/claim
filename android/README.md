# 安卓手机端自动领取

独立 Android App，在手机本机通过用户主动启用的无障碍服务操作目标钱包。**运行不依赖电脑、WDA、ADB 或 Root**。支持 Android 8（API 26）及以上作为兼容目标，实际钱包及系统须真机适配验证。

## 功能

- 悬浮控制：开始、停止、打开设置、拖动位置、隐藏。
- 网络费明确为 0：取消弹窗、返回网页、等待后重试；默认 1 秒。
- 网络费大于 0：确认、输入本机保存的密码、再次确认。
- 只在新出现的明确提交成功提示后计数。默认成功 1 次，设为 0 则不限。
- 金额使用 BigDecimal，两次费用核对一致后才操作，正费用确认前再次读取。
- 锁屏、熄屏、切离钱包、金额含糊、费用变化、错误提示、元素重复或超时均暂停，不自动重发。
- 钱包密码按包名独立保存：Android Keystore AES-GCM 加密，应用禁用备份；设置页面禁止录屏并关闭密码自动填充和状态保存。
- 不申请网络权限，不上传屏幕、节点或密码；不记录完整界面日志。节点面板只在内存展示，输入字段的文字和描述隐藏。

## 手机端使用

1. 安装构建得到的 APK，打开“自动领取”。首次安装可能需要允许来自当前安装来源的应用安装。
2. 填写**目标钱包 Android 包名**（不是名称，也不是 iOS Bundle ID）、间隔和次数，保存。包名可从钱包应用信息或官方应用商店链接确认。
3. 输入钱包密码，点击保存。密码只属于这台手机上的此钱包包名，不会同步到其他设备。
4. 点击“开启 / 管理无障碍服务”，阅读用途说明，同意后在系统设置中手动启用本服务。若系统对侧载应用限制此设置，只能通过系统允许的用户设置授权；本 App 不绕过限制。
5. 填写定位规则。可以先填写钱包包名并保存，再手动打开钱包和网页，用悬浮“节点”按钮采集候选规则。
6. 手动依次打开领取页、费用弹窗、密码页、成功提示，在悬浮栏选择阶段并点击“验证”。验证只读，不会提交或输入密码。
7. 四阶段验证通过后，手动返回领取页、清除旧成功提示，点击悬浮“开始”。
8. “停止”立即阻止后续步骤，已经发出的交易无法撤回。隐藏悬浮栏、打开 App 设置、服务中断或销毁都会停止，不会自行恢复。

每次开始重新计数。暂停后先检查实际交易结果，再回到领取页开始新任务。成功次数指钱包提示“已提交”，不是链上最终确认。

## 定位规则

每个规则必须唯一匹配可见节点：

```text
text=全部领取
id=com.example.wallet:id/network_fee
class=android.widget.Button && text=确定
class=android.widget.EditText
```

支持 `id`（资源 ID）、`text`（精确文字）、`desc`（精确无障碍描述）、`class`（完整控件类名），通过 `&&` 组合。不会默认选第一个节点或使用固定坐标盲点。文字本身含 `&&` 时请使用其他字段定位。

必填：领取页标识、领取按钮、费用加载完成标识、费用金额、取消、第一次确认、密码框、密码页确认、成功提示。错误提示可选但建议配置，命中时立即暂停。

采集结果只是候选：动态费用文字不能写入费用定位规则，优先选稳定资源 ID；如果没有唯一稳定标识，应调整适配，不能直接运行。提交成功标识必须只在本笔提交后出现，不能匹配常驻交易历史。修改包名或规则会使旧验证失效。

可解析纯数值、标准千分位及常见单位，例如 `0`、`0.0001 ETH`、`1,234.56 USDT`。`加载中`、`≈0`、`<0.01`、多个金额、科学计数法等都拒绝。

## 已知边界

本版直接读取无障碍节点，**不包含 OCR、录屏和坐标点击回退**。部分 WebView、自绘控件或钱包敏感界面不开放节点，密码控件可能拒绝 ACTION_SET_TEXT；遇到这些情况不能保证适配，需要目标钱包的实际界面进一步开发。不会伪装成辅助残障工具或绕过敏感视图保护。

手机应保持解锁、钱包在前台。悬浮栏可拖开以避免挡住按钮；系统或厂商后台管理可能终止服务，终止后不会恢复交易。App 不阻止锁屏，不会自动取消系统限制。

这是用户自行安装使用的自动化工具，未执行商店上架、签名发布或 Google Play 审核。

## 构建与检查

使用 Android Studio 打开本目录（Gradle 8.11.1、AGP 8.9.2、JDK 17、SDK 35），或在安装好上述工具后运行：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows 使用 `gradlew.bat`。调试 APK 输出 `app/build/outputs/apk/debug/app-debug.apk`，可以传到手机后直接安装；运行时不需要构建电脑。调试签名适合自行测试，正式分发需自行使用受保护的发布密钥签名。不同签名的安装包不能直接覆盖升级。

纯 Java 流程检查不依赖 Android SDK：

```sh
mkdir -p /tmp/walletclick-java-checks
javac -d /tmp/walletclick-java-checks app/src/main/java/com/walletclick/android/Flow.java app/src/test/java/com/walletclick/android/FlowChecks.java
java -cp /tmp/walletclick-java-checks com.walletclick.android.FlowChecks
```

GitHub Actions 构建定义位于项目根目录 `.github/workflows/android.yml`。本次不会创建仓库或自动推送。

## 真机验收

先验证节点与四个阶段，再测试零费取消、正费输入、次数与不限、旧成功提示、错误密码、切后台、锁屏和停止。尤其检查费用节点只读到网络费、密码输入框接受系统输入、成功提示不误计数。没有真机验收前，不把模拟流程检查当作钱包兼容证明。
